# WNM-Educational Measurement and Evaluation Section Ver.1 — ระบบรับ–ส่งและตรวจสอบวุฒิการศึกษา

ต้นแบบ (Prototype) แบบไฟล์เดียว เปิด `index.html` ในเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งเซิร์ฟเวอร์
(ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และตัวอ่านไฟล์ Excel — SheetJS)

## บทบาทผู้ใช้
หน้าแรกมี 2 ทาง
- **เจ้าหน้าที่** — เข้าด้วยรหัสผ่านเจ้าหน้าที่ (รหัสเริ่มต้น `admin1234` เปลี่ยนได้ที่ ⚙️ ตั้งค่า) → Dashboard, รับหนังสือ (สแกน/อัปโหลดให้ระบบกรอก + กดรับคำขอออนไลน์), หนังสือส่งออก, ตรวจสอบ, ฐานข้อมูลผู้สำเร็จการศึกษา, ค่าบำรุงการศึกษา, ติดตามสถานะ, รายงาน, ตั้งค่า
- **หน่วยงานภายนอก** — ลงทะเบียนด้วยอีเมล+รหัสผ่าน แล้วเข้าสู่ระบบ → แจ้งสถานะจากเจ้าหน้าที่, ส่งคำขอตรวจสอบคุณวุฒิ (กรอก+แนบไฟล์ หรือให้ระบบอ่านจากไฟล์หนังสือ), ตรวจสอบสถานะ/ผล และดาวน์โหลดหนังสือตอบกลับ PDF
- บัญชีทดลอง: `hr@thaismart.example.com` / `demo1234`

> **2 โหมด**
> - **ออนไลน์ (Supabase)** — เมื่อใส่คีย์ใน `config.js` และนำขึ้นเว็บ ข้อมูลเก็บบน Supabase เจ้าหน้าที่ใช้บัญชีอีเมลรายคน หน่วยงานลงทะเบียนแล้วรออนุมัติ ดูขั้นตอนที่ **SETUP-SUPABASE.md**
> - **ทดลอง** — ถ้ายังไม่ใส่คีย์ ข้อมูลเก็บในเบราว์เซอร์เครื่องเดียว (หน้าตัวอย่างใน claude.ai เป็นโหมดนี้เสมอ)

## โครงสร้าง
- `index.html` — โครงหน้า
- `style.css` — ธีมชมพู/แถบสีรุ้งของโรงเรียน + dark mode + รูปแบบหนังสือราชการ A4
- `app.js` — ข้อมูล การจับคู่ การนำเข้าไฟล์ และทุกหน้าจอ
- `gas/Code.gs` — บริการส่งอีเมลผ่าน Google Apps Script (ติดตั้งครั้งเดียว)
- `config.js` — URL และ anon key ของ Supabase
- `supabase/schema.sql` — ตาราง สิทธิ์ และที่เก็บไฟล์ (รันใน SQL Editor)
- `SETUP-SUPABASE.md` — ขั้นตอนติดตั้งระบบออนไลน์

## ส่งหนังสือแจ้งผล
ในหน้าหนังสือ (📤 หนังสือส่งออก → ดูหนังสือ)
- 💾 ดาวน์โหลด PDF — ได้ไฟล์ A4 (แบบที่ 1 มีหน้าบัญชีรายชื่อแนบท้าย)
- 📧 ส่งอีเมล — แก้ข้อความได้ แนบ PDF อัตโนมัติ ส่งผ่าน Google Apps Script (ดู gas/Code.gs) หรือดาวน์โหลด PDF ไปส่งเองแล้วกด "บันทึกว่าส่งอีเมลแล้ว"
- 📮 ส่งไปรษณีย์ — พิมพ์ซองจดหมาย DL (ตราครุฑ ที่อยู่ผู้ส่ง/ผู้รับ) บันทึกวิธีส่งและเลขพัสดุ หน่วยงานกดติดตามพัสดุได้จากหน้าตรวจสอบสถานะ

## เลขทะเบียนรับ / เลขหนังสือส่ง
- เลขทะเบียนรับ: เจ้าหน้าที่กรอกเองตามเลขที่งานธุรการออกให้ (ตอนรับหนังสือ และตอนกดรับคำขอออนไลน์) ระบบเตือนถ้าเลขซ้ำ
- เลขหนังสือส่ง: กำหนดช่วง "ตั้งแต่เลขที่ … ถึงเลขที่ …" ที่ ⚙️ ตั้งค่า ระบบออกเลขถัดไปให้ และแจ้งเมื่อใกล้หมด/หมดช่วง

## ค่าบำรุงการศึกษา
นำเข้าจากไฟล์ Excel/CSV ได้ คอลัมน์: รหัสประจำตัว, ชื่อ-สกุล (ถ้ามี), ภาค/ปีการศึกษา, รายการ, จำนวนเงิน, ชำระแล้ว หรือ ค้างชำระ · รายการเดิม (นักเรียน+ภาค+รายการเดียวกัน) จะถูกอัปเดต · แถวที่ไม่พบรหัสในฐานข้อมูลจะแจ้งให้ทราบ

## ผลการตรวจสอบในหนังสือ
- ตารางผล: ชื่อ-สกุล (คำนำหน้า/ยศ บังคับ ชื่อทั้งหมดอยู่บรรทัดเดียว) · เลขประจำตัว · ระดับชั้น · วันที่สำเร็จ · เกรดเฉลี่ย (เปิด/ปิดได้) · **สำเร็จการศึกษาแห่งนี้จริง** (✓) · **หมายเหตุ** ระบุปัญหาที่พบ เช่น ศึกษาต่อสถาบันอื่น (มีตัวเลือกสำเร็จรูป)
- มีรายชื่อคนเดียว ไม่แสดงคอลัมน์ลำดับที่
- เลข ปพ.1 (ชุดที่ / เลขที่) แสดงให้เจ้าหน้าที่เห็นในขั้นตอนตรวจสอบ ถ้ายังไม่มีกรอกได้ทันที หรือนำเข้า CSV (รหัสประจำตัว, ชุดที่, เลขที่) · ไม่แสดงในหนังสือตอบและหน้าหน่วยงาน

## สำเนา ปพ.1 แนบไปกับหนังสือตอบ
- อัปโหลดสำเนา ปพ.1 (PDF หรือรูป) ได้ที่หน้าตรวจสอบ (ลิงก์ "แนบสำเนา ปพ.1" ในช่องข้อมูลในฐานข้อมูล) หรือในหน้าหนังสือตอบ แผง "สำเนา ปพ.1 แนบไปกับหนังสือตอบ"
- ไฟล์เก็บกับข้อมูลนักเรียน ใช้ซ้ำได้เมื่อมีหน่วยงานขอตรวจคนเดิม เห็นได้เฉพาะเจ้าหน้าที่ (ระบบออนไลน์เก็บใน Storage: attachments/pp1/...)
- เปิดให้อัตโนมัติเมื่อหน่วยงานเป็น สกร./กศน./ศูนย์ส่งเสริมการเรียนรู้ ปิด/เปิดเองได้ทุกหนังสือ
- แนบเฉพาะผู้ที่ยืนยันว่าสำเร็จการศึกษาจริง ต่อท้ายหนังสือเป็นหน้าละ 1 แผ่น พร้อม "สำเนาถูกต้อง" (เลือกผู้รับรองได้) และข้อความกำกับการใช้
- เพิ่ม "สำเนาระเบียนแสดงผลการเรียน (ปพ.1) จำนวน N ฉบับ" ในสิ่งที่ส่งมาด้วยให้อัตโนมัติ และรวมอยู่ใน PDF ที่ดาวน์โหลด ส่งอีเมล และที่หน่วยงานดาวน์โหลดเอง
- โหมดทดลองเก็บไฟล์ในเบราว์เซอร์ ซึ่งมีพื้นที่จำกัด (ประมาณ 10–15 หน้า)

## ผู้ลงนามและลายเซ็น
⚙️ ตั้งค่า › ผู้ลงนามและลายเซ็น — ใส่ชื่อ ตำแหน่ง และภาพลายเซ็น (อัปโหลดรูปหรือวาดบนจอ) ของ ผู้อำนวยการ นายทะเบียน หัวหน้างานวัดและประเมินผล และเจ้าหน้าที่งานทะเบียนและวัดผล พร้อมค่าเริ่มต้น
ในหน้าหนังสือแต่ละฉบับเลือกได้ว่า
- ใครลงนามหนังสือ: ผู้อำนวยการ หรือ นายทะเบียน (ปฏิบัติราชการแทนผู้อำนวยการ)
- ใครลงนามร่วม: แสดงท้ายหนังสือ หรือในบัญชีรายชื่อแนบท้าย (แบบที่ 1)
- ใส่ภาพลายเซ็นหรือเว้นว่างไว้ลงนามด้วยปากกา

## ไฟล์ Excel ฐานข้อมูลนักเรียนที่จบการศึกษา (แบบฟอร์มงานทะเบียน)
หน้า 🎓 ฐานข้อมูลผู้สำเร็จการศึกษา › "นำเข้าฐานข้อมูลนักเรียนที่จบการศึกษา" › เลือกไฟล์ + ระดับชั้นที่จบ + วันที่จบ › นำเข้า
ระบบอ่านคอลัมน์ตามหัวตาราง: เลขประจำตัวนักเรียน, เลขประจำตัวประชาชน, ชุดที่ ปพ.1, เลขที่ ปพ.1, เลขที่ ปพ.2, คำนำหน้า, ชื่อ, ชื่อสกุล, วัน/เดือน/ปีเกิด, บิดา, มารดา, หน่วยกิต, ผลการเรียนเฉลี่ยตลอดหลักสูตร, ผลการประเมิน 3 ด้าน, หมายเหตุ, หลักฐานที่ไม่มี (ใส่ลำดับคอลัมน์), ประวัติค้างชำระค่าบำรุงการศึกษา (สร้างรายการค้างชำระให้อัตโนมัติ)
กดปุ่ม "ดาวน์โหลดแบบฟอร์มเปล่า" เพื่อได้ไฟล์หัวตารางที่ถูกต้อง

## ไฟล์ CSV ฐานข้อมูลผู้สำเร็จการศึกษา
```
รหัสประจำตัว,ชื่อ-สกุล,ระดับชั้นที่จบ,วันที่จบ
09483,นางสาวตัวอย่าง ใจดี,ม.6,31/03/2569
```
เพิ่มคอลัมน์ `เลขบัตรประชาชน` และ `GPA` ได้ · วันที่ใช้ พ.ศ. (dd/mm/yyyy) หรือ "31 มีนาคม 2569"

## ไฟล์ ปพ.3
เลือกไฟล์ → เลือกระดับชั้น (ไฟล์ไม่ระบุ ม.3/ม.6 ในตัว; ถ้าชื่อไฟล์เป็น PP3-2568-6.xls ระบบเลือกให้) → นำเข้า
ระบบอ่านทุกแถวที่มีคำนำหน้าชื่อ + รหัส/เลขบัตร และหาวันที่อนุมัติจบจากบล็อก "อนุมัติ" ท้ายเอกสาร ถ้าไม่พบใช้วันที่ที่กรอก

## ข้อจำกัดของต้นแบบ
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้นเท่านั้น ไม่ซิงก์ระหว่างเครื่อง
- OTP เป็นการจำลอง (แสดงใน "กล่องอีเมลจำลอง") — ของจริงต้องสร้างและตรวจ OTP ที่เซิร์ฟเวอร์ แล้วส่งผ่านบริการอีเมล
- ไม่มีระบบ Login เจ้าหน้าที่

## ขั้นต่อไปสำหรับใช้งานจริง
ฐานข้อมูลออนไลน์ (เช่น Supabase/PostgreSQL) · Login เจ้าหน้าที่และสิทธิ์ผู้ใช้ · OTP E-mail จริงฝั่งเซิร์ฟเวอร์ (เก็บแบบ hash, จำกัดความถี่) · Audit Log · PDF หนังสือราชการฝั่งเซิร์ฟเวอร์ · QR Code สำหรับติดตามสถานะ
