# Smart Speaking Test v2

## โครงสร้าง
- 20 ข้อ
- คะแนนเต็ม 30 คะแนน
- ข้อละ 1.5 คะแนน
- แยกเป็น Content 0.5 + Grammar 0.5 + Speaking 0.5

## การแก้ไขสำคัญ
- คำถาม 20 ข้อยึดตามชุดประโยคจากภาพมากขึ้น
- ไม่ใช้ keyword เดี่ยวเป็นเกณฑ์ว่าถูก
- Smart Check ตรวจ phrase/structure
- Speaking 0.5 ต่อข้อถูกเว้นไว้ให้ครูตรวจเสียงจริง
- Dashboard แสดงคะแนน Auto Content+Grammar แยกจากคะแนนเต็ม 30
- Export CSV

## หมายเหตุ
Speech Recognition ของ browser ให้ transcript ไม่ได้บันทึกไฟล์เสียงจริง และไม่สามารถประเมิน pronunciation/fluency ได้อย่างน่าเชื่อถือด้วยตัวเอง จึงให้ครูเป็นผู้ตรวจส่วน Speaking 0.5 คะแนนต่อข้อ
